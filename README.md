# SmartShop Admin Panel ⚙️🛠️
Welcome, Admin! This is your headquarters for SmartShop – the place where all the magic happens behind the scenes. From adding exciting new products to managing user activities, this powerful admin panel gives you full control over the entire SmartShop experience in real-time.

## Overview:
🚀 Effortless Product Management: With just a few clicks, you can create, edit, and oversee every aspect of SmartShop, ensuring a seamless experience for users.

🛠️ Powerful Admin Tools: Manage products, users, and categories all in one place, keeping your store running smoothly and efficiently.

🧼 Real-Time Updates: Instantly see the effects of your changes as they are reflected across all user devices in real-time.

## Key Features:
🆕 Add New Products: Easily upload new products, complete with images, prices, and categories, keeping your inventory up-to-date.

🔧 Manage Existing Products: Update or delete products at any time, ensuring users always see accurate and relevant options.

📊 User Activity Management: Monitor user shopping habits, manage order histories, and track their favorite items for deeper insights.

📦 Product Categorization: Organize products into categories and filters, making it easier for users to find what they need.

🔒 Admin-Only Login: Keep the admin panel secure with Firebase Authentication, ensuring only authorized admins have access.

## Tech Stack:
Flutter Web: A responsive, user-friendly interface that works seamlessly across any device, allowing admins to manage the store from anywhere.
Firebase Auth: Restricts access to authorized admins only, ensuring security and control.
Cloud Firestore: A real-time database that efficiently manages products, categories, and user data for instant updates.
